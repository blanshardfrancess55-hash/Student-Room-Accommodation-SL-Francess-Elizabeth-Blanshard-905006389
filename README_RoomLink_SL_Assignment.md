## 1. Project Overview

RoomLink SL is a student accommodation website prototype created as part of a web design assignment. The purpose of the website is to demonstrate how students can browse and compare sample accommodation options in Sierra Leone from one place. The interface presents room types, monthly prices, locations, facilities, and ways to contact a provider.

The website uses a clean, responsive layout intended to be easy to navigate on both desktop computers and mobile devices. Its design includes room photography/visuals and separate sections for the main pages.

## 2. Problem Statement

Students who are moving to a new town or attending college or university may find it difficult to locate suitable accommodation. Information about room prices, facilities, location, and contact details can be scattered across different sources, making options hard to compare.

## 3. Aim and Objectives

**Aim:** To design a simple and user-friendly website that helps students explore student accommodation options.

**Objectives:**
- Present sample accommodation listings in an organised format.
- Display room types, locations, prices, and facilities.
- Provide search and filtering controls to help users narrow down options.
- Include clear navigation between the website sections.
- Provide an About page explaining the project and its mission.
- Provide a Contact page layout with contact information and an enquiry form.
- Apply responsive design principles for desktop and mobile screens.

## 4. Target Users

- New and continuing university or college students.
- Students relocating from another town or district.
- Parents and guardians helping students find accommodation.
- Accommodation providers who may wish to advertise rooms in a future version.

## 5. Main Website Sections

- **Home:** Introduces RoomLink SL and helps visitors begin looking for accommodation.
- **About Us:** Explains the purpose of the website and presents the project mission alongside an accommodation image.
- **Rooms / Explore Rooms:** Displays sample room listings and supports browsing and filtering.
- **Contact:** Presents contact information and a message form layout for enquiries.
- **Navigation and footer:** Provide consistent links and supporting information throughout the site.

## 6. Tools and Technologies

- **HTML5** — page structure.
- **CSS / Tailwind CSS** — layout and visual styling.
- **JavaScript** — interactive behaviour.
- **React** — interface components and state management.
- **Babel Standalone** — allows the JSX used in this prototype to run in the browser.
- **Google Fonts (Inter)** — typography.
- **Unsplash / external image resources, where used** — accommodation imagery.

Some libraries, fonts, and images are loaded from external services, so an internet connection is required for all external resources to display correctly.

## 7. How to Run the Website

1. Download the project ZIP file.
2. Extract the ZIP file into a folder on your computer.
3. Open the extracted project folder.
4. Double-click **`RoomLink SL — Student Accommodation (1).html`** to open it in a modern browser such as Google Chrome, Microsoft Edge, or Firefox.
5. Keep the device connected to the internet so externally hosted scripts, fonts, and images can load.

No database or local server is required for this front-end demonstration.

## 8. Project Limitations

- This is a front-end academic prototype, not a live accommodation booking service.
- Room listings, prices, contact details, and other listing information are sample data and have not been verified as real offers.
- The contact form is a visual/demo feature and does not send messages to a real email inbox unless a backend service is added.
- User accounts, database storage, real-time availability, booking, and online payment are not implemented.
- External resources may not load when the device is offline or the external service is unavailable.

## 9. Future Improvements

- Connect the website to a database for managing listings.
- Add secure registration and sign-in for students and accommodation providers.
- Allow providers to upload verified room photos and update availability.
- Connect the contact form to a backend or email service.
- Add a real map and verified location details.
- Add booking requests, saved listings, and stronger validation.
- Test the website with students and improve accessibility based on feedback.

## 10. Conclusion

RoomLink SL demonstrates how a website can organise accommodation information and make it easier for students to browse sample room options. The project applies basic web design and front-end development concepts, including navigation, responsive layouts, listing cards, and enquiry interfaces. Further development and verification would be required before the website could be used as a real accommodation service.
